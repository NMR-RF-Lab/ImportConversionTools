# Import Conversion Tools
Compilation of MATLAB functions for importing MRI and MRS datasets.
Code was designed for use with Siemens Verio 3T MR scanners running VB19 software and Varian/Inova scanners, but may be applicable for other use cases given adequate modifications. 
Siemens-related code requires mapVBVD: https://github.com/pehses/mapVBVD
